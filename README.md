# 低空研习 · L3 学习与自测计划 2.0

手机优先的静态学习工具。内置原500道单选与新增500题（300单选、200多选），保留逐题解析、资料定位、错题复习、重点专项、收藏笔记与学习备份。

在线使用：https://chenweihua123.github.io/low-altitude-l3-study/

## 学习路径

1. 首页分别显示去重已看、组内已测、整库本轮覆盖。
2. 学习目录按章节分成固定小组，每组约15题、最多18题，章内均衡；每组各有断点。看题时预选正确答案、直接阅读解析，不产生答题成绩。
3. 组内自测检查同一学习组，题序和选项打乱，交卷后统一看解析；可随时退出再继续。
4. 整库自测先一次性固定整轮题单，每卷最多50题。新增题库500题分10卷，每卷30单选、20多选；同轮各卷无重复，覆盖全部可用题。原题库5题暂缓，495道可用题的末卷为45题。
5. 交卷后的实际作答计入覆盖，答错同时进入错题集。未答不计覆盖、不算错题，可补答；补答不重复计分，首测成绩保留。组内覆盖与整库覆盖独立。
6. 开启新轮保留旧轮、学习、错题、笔记和收藏；可切回旧轮。原v4进度自动迁移，旧30题随机测试保留历史，不冒充新轮覆盖。

学习自测规则不代表官方认证考试规则。课程重点和个人常错单独标注，不宣称真实考试题频。

## 免费手动云同步

平时数据保存在当前浏览器。只有点击“手动云同步 → 同步一次”才连接GitHub，读取两端记录、合并并保存。没有后台自动同步。

公开站点仓库只放代码与已获授权公开的题库；个人进度使用另一个**私有仓库** `ChenWeihua123/low-altitude-l3-progress`。GitHub Free支持私有仓库与公开仓库的Pages，不需要为这个方案开通付费套餐、绑定支付方式或启用其他云服务：[GitHub官方套餐说明](https://docs.github.com/en/get-started/learning-about-github/githubs-plans)。

首次设置（手机、电脑各设置一次）：

1. 打开工具的“我的 → 手动云端同步”，点“创建访问钥匙”，登录GitHub。
2. 在 `Repository access` 选 `Only select repositories`，只勾选 `low-altitude-l3-progress`。
3. 在 `Repository permissions → Contents` 选 `Read and write`，其他权限保持默认。
4. 点 `Generate token`，把生成的长码复制到工具的“粘贴访问钥匙”。不要发到聊天里。默认90天到期，到期后重新生成替换即可。
5. 自己的设备可勾选“在这台个人设备记住钥匙”，然后点“同步一次”。看到成功提示后，另一台设备也点一次，即可合并各自已有进度。两台设备可使用同一把钥匙，也可分别创建权限相同的钥匙。

日常用法：**离开这台设备前同步一次；换到另一台设备时同步一次。** 仅一端点击不会让另一端立即更新。

访问钥匙默认只在当前标签页临时保存；明确勾选后才保存在该浏览器。它不会进入学习备份、云端进度或公开代码。工具会核实仓库是私有仓库；发现公开仓库会拒绝上传。云端记录使用事件去重和文件SHA检查合并，遇到冲突重新读取，不整份覆盖另一端记录。

GitHub在实际手机日常网络的连接情况需由首次同步验证。如果无法直连，工具仍可本地学习、导出/恢复备份，不需要改用收费服务。未完成真实写入前不会显示“已同步”。

## 本地开发和发布

Node.js内置模块，无第三方构建依赖：

```sh
npm test
npm run build
```

源代码在 `src/`，构建脚本为 `scripts/build.mjs`；生成根目录 `index.html` 和限定项目路径的 `sw.js`。生成独立离线HTML可运行 `node scripts/build.mjs /absolute/path/offline.html`。

GitHub Pages使用 `main` 分支根目录，保留 `.nojekyll`。直接发布静态文件，无需服务器。首次联网完整打开后可离线使用，也可使用独立HTML；不同浏览器、网址或离线文件之间本机存储各自独立。
