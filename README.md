# 低空研习 · L3 手机刷题

手机优先的静态学习工具，内置原500道单选与新增500题（300单选、200多选）。支持学习模式、逐题练习、错题复习、重点专项、收藏笔记、限时自测与数据备份。

## GitHub Pages 设置

将这些文件放在公开仓库 `low-altitude-l3-study` 的 `main` 分支根目录，在 Settings → Pages 选择 Deploy from a branch，分支为 main，目录为 / (root)。不需要付费服务器或构建工具。

## 公开内容

发布这个包后，工具代码、内置1000题及解析、课程学习要点和原文摘录均可被公开访问。这个包不包含原始课程PDF、抓取快照、登录信息或个人学习备份。

## 学习记录

答题、已阅、错题、笔记与收藏只保存在当前浏览器。迁移到新网址或新手机之前，请导出学习备份，再在新页面恢复。

学习辅助题库，并非官方考试题库。
